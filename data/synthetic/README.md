# RoadSense Synthetic Kerala-like Demonstration Dataset

This is a synthetic demonstration dataset generated for the RoadSense hackathon prototype. It is designed to statistically and physically resemble smartphone sensor observations collected from buses travelling on Kerala-like roads. It is NOT real government bus data and does not represent measured road conditions.

The generator creates coherent bus passes, GPS traces, correlated accelerometer/gyroscope signals, road-event signatures, false-positive candidates, repeated observations, segment summaries, and GeoJSON road geometry. Ground-truth labels are evaluation-only; the application should not use them as detection inputs.
